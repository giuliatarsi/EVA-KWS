# EVA electrical schematic

Open `eva_schema.kicad_sch` in KiCad 10. The schematic includes embedded symbol definitions and shows the prototype wiring, including the optional battery. For the USB bench test, leave the battery disconnected and follow the [vibration test instructions](../../firmware/tests/eva_vibration_test/README.md).

This is a wiring schematic. The XIAO symbol refers to an external footprint library for PCB layout.
