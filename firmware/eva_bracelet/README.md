# Main bracelet application (scaffold)

This is the future integration entry point. It currently only prints a status message: it does not acquire audio, run the detector, vibrate or transmit BLE. Use `../eva_continuous` for the working continuous detector.

Planned modules: audio_capture -> keyword_detector (EVA_MFCC + CNN) -> alarm_manager -> ble_service. Alarm handling must not block audio acquisition. `config.h` will collect pin assignments and validated interaction settings. Model arrays are generated by deployment tools and excluded from Git. The empty .h/.cpp files mark future responsibilities, not implemented interfaces.
